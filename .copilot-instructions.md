# Contexte du projet CGLOBAL

## Objectif
Post-installation automatisée Windows 11 (25H2) pour MSP.

## Contraintes techniques
- PowerShell 5.1 uniquement
- Scripts modulaires et indépendants
- Scripts relançables (idempotents)
- Logging dans C:\_CGLOBAL\Logs\
- Niveaux de log : INFO, OK, WARN, ERROR

## Architecture
- Batch principal : Run_Install.cmd
- Scripts PS1 dans : _CGLOBAL/PS1/
- Cache installers : _CGLOBAL/installers/
- Logs : C:\_CGLOBAL\Logs\

## Décisions importantes
- Menu contextuel classique : script 02 à exécuter par utilisateur
- Profil par défaut : script 12 modifie NTUSER.DAT
- Pas de contournement UCPD pour l'instant
- Firefox : package Mozilla.Firefox.fr
- WinGet : installation depuis cache local prioritaire
